# challenges

Coding challenges and project ideas.

This document will be periodically updated, so do check back in every now and then to look for new challenges.

## Quick challenges

These are challenges or quick projects designed to be possible to create within a 30 minute session. If you run out of ones here,
there are large swathes more on websites like:

- [codingbat](https://codingbat.com/) lots of simple problems with a main focus on arrays and strings
- [bebras](https://www.bebras.uk/index.php?action=user_competitions) past questions from the UK bebras competitions
- [advent of code](https://adventofcode.com/2025/events) past questions from Advent of code (These get quite hard!)
- [rosetta code](https://rosettacode.org/wiki/Category:Solutions_by_Programming_Task) a huge number of problems of wildly varying difficulty (some quite simple, some quite hard)
- [leetcode](https://leetcode.com/problemset/) programming job interview questions
- [neetcode](https://neetcode.io/practice/practice/neetcode150) programming job interview questions

There are also many resources to learn programming.

- [code.org](https://code.org/) very basic programming. Only use this if you have literally no idea what you are doing, otherwise it is probably a waste of time.
- [bro code](https://www.youtube.com/channel/UC4SVo0Ue36XCfOyb5Lh1viQ) beginner to intermediate level for a number of programming languages (python, java, javascript, c#, c, c++, html/css)
- [codeacademy](https://www.codecademy.com/) beginner to intermediate (?) level for a huge number of languages. However does pressure you to pay a *lot*
- [boot.dev](https://www.boot.dev/) similar to codeacademy. Focuses on the python and go programming languages, as well as git and linux. I personally used this to learn the basics of go before just using the web afterwards
- there are also huge numbers of other tutorials and websites which exist on the web - so many that it would be infeasible to list them all. If you want to add something to this list, just add a [pull request](https://docs.github.com/en/pull-requests/reference/pull-requests)

### Basic

- make a simple calculator (with or without validation of input)

### Classics

These are some classic coding challenges. But just because they are simple doesn't mean that you can't get deep into them.
Some of these are quite important problems and have many possible solutions.

- list prime numbers up to some number `N`
- define the factorial function without imports.
- Sort a list of numbers into ascending order.

### Difficult

- make a pretty printer
- implement queue/stack data structures
- implement a circular list


## Project ideas

Any ideas prefixed with `(scratch)` are intended to be completed in either [scratch](https://turbowarp.org/editor) or [goboscript](https://aspiz.uk/goboscript/ide)

## Simple

- simple flashcard app (optionally a basic Spaced-Repetition-System)
- make a brainf interpreter/compiler
- implement and display easings
- make a simple custom image format
- implement 3y3 encoding
- recreate (part of) some game, e.g. geometry dash
- make a text adventure using a while loop or recursion (is the latter
  unreliable?), consider the complexities of keeping track of where you are

## intermediate

- ray reflector
- line-rectangle clipping
- line-circle clipping
- bezier curve rendering
- make a calculator web server
- make a json/xml parser by hand
- make a discord/whatsapp bot
- make some system to handle colours in scratch and apply basic shader-like
  effects
- (scratch) algorithms to draw shape outlines like segments, arcs, circles,
  ngons, etc
- (scratch) using emojis, detect the user's OS.
- make an image-to-ascii converter

- something based on iterators?
- something based on hash-based data structures?

## advanced

- implement chess
- implement a linear algebra library (watch 3b1b and implement the corresponding
  computations)
- implement `datetime` from scratch, maybe even in scratch
- intersection algorithms for line-circle-ngon-ellipse etc etc
- (scratch) optimised filling algorithms for triangles, rectangles, quads,
  segments, arcs
- implement a godot/unity-like `node` system in scratch
- make a webscraper for some website, e.g. kegsnet
- ear clipping
- bezier curve algorithms (pomax)
- line clipping
- convex ngon clipping
- check if point in complex polygon
- (scratch) handle unicode

## very advanced

- FFT-based wav-file "rendering" in scratch (i.e. by using many sounds or
  clones+pitch effect) to recreate any sound at runtime
- 3d raytracing/raymarching/raycasting
- shader development
- parsers/lexers
- bsp/triangle-based 3d->2d renderers
