# Challenges from Friday 23rd October 2026

This week's challenges are about password security, authentication, and code obfuscation. We have added more levels so you can enjoy doing it during half term.

## Beginner challenge

Write a Python program that stores a password in the code. 
Make the user input a guess and if they fail to enter the correct password within 10 attempts, exit the program (do nothing).
 
## Intermediate challenge

Extend the program to do something special when the user logs in successfully (e.g. outputting a specific message) 
and make it tell the user the number of attempts they have left during login.
 
## Advanced challenge

If someone is looking at your source code, they know your password! 
Store the password in a file and allow the user to login that way.

## Master challenge

Allow the user to create an account whenever the program starts, the details of which are stored in a file.
Once the user logs in to the account, allow them to change their password, but not their username.
 
## Supreme challenge

Encrypt the program logic after user's password so that even if you look at the source code, it does not
let you know what it will do unless you give it the correct password!
(Hint: Something like `base64` could work!)

## Champion Challenge

Make the program make sure it is not being debugged, as well as make sure its file has not been changed from the original.
