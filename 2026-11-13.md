### Intermediate challenge

Python also allows you to create and delete directories (aka folders), using the `os` module:

```py
import os

os.mkdir("new folder") # creates a directory called "new folder". 
```

However, note that this code will fail if there is already a folder called `new folder`.

To fix this, we can first check if the folder exists, using the `os.path` module (this is imported as part of `os`)

```py
import os

if not os.path.exists("new folder"):
  os.mkdir("new folder")
```

This program will first check if *a file* **OR** a directory called `new folder` already exists.
It will only try to create a folder in that location if there is nothing there yet.

### Your challenge:

Make a program that takes in the name of a folder from the user, an create the folder if it doesn't already exist.
If the folder already exists, add `(1)` to the end of the name and try again.
If *that* already exists, change the `(1)` to a `(2)` and try again. Repeat until you are able to create the folder.

This is how windows handled duplicate file names. 

Remember:

- `import os` to import `os` and `os.path`
- `os.path.exists(PATH)` to check if `PATH` is a file or directory that exists
- `os.mkdir(PATH)` to create a directory at `PATH`

## Advanced challenge

The `os` module can also be used to look for files and directories. The `os.listdir(PATH)` function returns a
list of all the files and directories in the `PATH` directory.

e.g. For a folder like this:

<img width="583" height="200" alt="image" src="https://github.com/user-attachments/assets/8a00d6aa-a657-415c-b250-66cb5a2b5cb4" />

```python
import os
print(os.listdir("."))  # NOTE: When "." is used as a path, it means "current directory". I.e., we are asking python: "List the files in *this current directory*"; i.e. list the files here
```

output: `['document.txt', 'beginner.py', 'subdirectory']`

Note that the `os.listdir` function does not distinguish between files and directories. 
To check if a path contains a file, use the `os.path.isfile(PATH)` function: 

```py
>>> os.path.isfile("subdirectory")
False
>>> os.path.isfile("beginner.py")
True
>>> os.path.isfile("document.txt")
True
```

Likewise, to check if a file is a directory or not, use the `os.path.isdir(PATH)` function:

```py
>>> os.path.isdir("subdirectory")
True
>>> os.path.isdir("beginner.py")
False
>>> os.path.isdir("document.txt")
```

## Supreme challenge

The `os` module provides a pretty powerful function called `os.walk`, which is used with for loops.
It will traverse a directory. What this means is that first its lists all the files and subdirectories in a directory,
then goes into each of the subdirectories and does the same. 
So in essence, it will list out every single file that directly or indirectly exists inside of a directory systematically.

Here is an example:

```txt
folder/
├── beginner.py
├── document.txt
└── subdirectory
    ├── hint1.txt
    └── hint2.txt
```

Here is a folder called `folder`. Inside of it there are 2 files: `beginner.py` and `document.txt`. There is also a directory in it called `subdirectory` which itself contains 2 more files: `hint1.txt` and `hint2.txt`.

We can traverse this folder using python and list out all the files:

```py
import os
for root, dirs, files in os.walk("folder"):
  print(root, dirs, files)
```

Here is the output:

```
folder ['subdirectory'] ['document.txt', 'beginner.py']
folder/subdirectory [] ['hint1.txt', 'hint2.txt']
```

First, it lists the directories (`dirs`) and the files (`files`) in `"folder"` (`root`).

Then, since there is a subdirectory, it does the same. But this time, the `root` path is not `folder`, but rather `folder/subdirectory`.
This is useful because python keeps track of where you are.
